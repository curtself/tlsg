# TLS Go toolkit

Application to manage various tasks for SSL and CSRs without needing to use IIS or openssl.

There are four main features provided by command line argument verbs:

- create
- finish
- info
- extract

## Create Command

Use the _create_ command to create a CSR and key file. The files will be saved in the current working directory.

```bash
Usage:
  tlsg create [flags]

Flags:
  -c, --cn string         Common name (required)
  -h, --help              help for create
  -k, --key string        External key file path (optional)
  -b, --keysize int       Key size in bits (optional)
  -s, --san stringArray   Subject Alternative Names (optional)
Examples:
#Basic CSR with an autogenerated key of 4096 bits
tlsg create --cn some-domain.org --san www.some-domain.org
#The same command but with short options
tlsg create -c some-domain.org -s www.some-domain.org
#CSR with an autogenerated key of 2048 bits
tlsg create --cn some-domain.org --san www.some-domain.org --keysize 2048
#CSR with an external key file (bit size depends on the key in file)
tlsg create --cn some-domain.org --san www.some-domain.org --key mykeyfile.key
#CSR with multiple SAN values
tlsg create --cn some-domain.org --san www.some-domain.org mail.some-domain.org api.some-domain.org
```
Even when you do not pass any SAN values the Common Name gets added as a DNS SAN. This generally makes installing the certificates easier with the various systems that need them.

The CSR is created with these Basic Constraints:
* Certificate Authority = false
* HasPathLengthConstraint = false
* PathLengthConstraint = 0
* Critical = false

Additionally, the key usage extensions are
* Digital Signature
* Key Encipherment

## Finish Command

Use the _finish_ command to complete a CSR by combining a signed certificate and the key file from a previous create step.

```bash
tlsg help finish
Usage:
  tlsg finish [flags]

Flags:
  -c, --certificate string   Certificate file path (required)
      --chain                Include the certificate chain (optional)
  -h, --help                 help for finish
      --include-root         Include the root certificate(s) in the chain (optional)
  -k, --key string           Key file path (required)
      --password string      Password for PFX file (required)
  -p, --pfx string           Pfx file path (optional)
  -v, --verbose              Verbose output

Example:
#Basic command to create a PFX
tlsg finish --cert cert-from-ca.pem --key some-domain.org.key --pfx cert-to-create.pfx --password s3cuReP4s$
#Create a full-chain PFX using the password in the environment variable 'sslpass'
tlsg finish -c cert-from-ca.pem -k some-domain.org.key --chain --include-root
```

## Info Command

Use the _info_ command to view details about a certificate or certificate request.

```bash
tlsg help info
Usage:
  tlsg info [flags]

Flags:
  -c, --cert stringArray   Certificate file list (optional)
  -r, --csr string         CSR file (optional)
  -h, --help               help for info
      --host stringArray   Host mappings in the form name=address
  -p, --password string    Password (optional, used with pkcs12/pfx files)
  -s, --short-summary      Show short summary (optional)
  -u, --url stringArray    URL list (optional)

Examples:
#Will show information about a csr
tlsg info --csr _dev.sdccd.edu.csr
#Will show information about a certificate
tlsg info --cert _dev.sdccd.edu.pem
#You can include both --cert and --csr
tlsg info --cert _dev.sdccd.edu.pem --csr _dev.sdccd.edu.csr
#You can include multiple certificates, seperated by spaces
tlsg info -c _dev.sdccd.edu.pem _test.sdccd.edu.pem
#You can also include multiple URLs, seperated by spaces
tlsg info -u https://myportal.sdccd.edu https://www.sdccd.edu
```

## Extract Command

Use the _extract_ command to extract any number of certificates from a file with a chain.

```bash
tlsg help extract
Usage:
  tlsg extract [flags]

Flags:
  -c, --cert stringArray   Certificate file
  -h, --help               help for extract
  -n, --number int         Number of certificates to extract (optional)
  -o, --output string      Output file path (optional)
  -p, --password string    Password (optional), used with pkcs12/pfx files)
  -s, --skip int           Number of certificates to skip (optional)

Examples:
#Will extract all certificates in the chain except the root, saving the extracted certs to a new file
tlsg extract -c _dev.sdccd.edu.pem -o _dev.sdccd.edu-webchain.pem
#will extract only the leaf/subject certificate
tlsg extract -c _dev.sdccd.edu.pem -n 1 -o _dev.sdccd.edu-subject.pem
#will extract only the intermediate certificate
tlsg extract -c _dev.sdccd.edu.pem -n 1 -s 1 -o _dev.sdccd.edu-intermediate.pem
```
